|---|---|---|

| Test-set layer selection | fixed in V2 probe path | selection is validation-only and audit checks it |

| Poker confounds and nuisance baselines | fixed in code, blocked on real metadata | `paper_confounds.py` implements bluff-vs-value, action/street/position/board/bet-size/equity matching, typed nuisance decodability (logistic for categorical, ridge for continuous), and train-fitted residualisation reporting unadjusted vs controlled AUROC. Each control reports `not_run` with a reason when metadata is absent; `analyze-confounds` CLI + 30 tests. |
| Cross-context transfer | fixed in code, blocked on second real context | `paper_transfer.py` fits probes on source-train rows, selects the activation layer using source-validation AUROC only, freezes that probe/layer, and evaluates only on target-context rows from the global held-out test partition. `run-transfer` writes `cross_context_results.json`; `figure_cross_scenario` renders the artifact-backed transfer matrix; the audit checks complete source-target coverage, target-test exclusion from selection, grouped CIs, and activation-axis to physical-layer provenance. `tests/test_transfer.py` includes a regression proving that changing target-test labels cannot change source layer selection. A real result still requires at least two real contexts. |
| Behavioral causal endpoint and controls | fixed in code, blocked on real run | `paper_causal.py`: primary endpoint is the model's own forced-choice answer distribution, `assert_endpoint_independence` refuses probe-derived endpoints, probe projection carried as `diagnostic_probe_projection` only. Full control set (random matched-norm, orthogonal, shuffled-label, wrong-layer, wrong-token, mismatched-prompt patching, nuisance direction) with paired grouped-bootstrap CIs. Audit fails a run missing any control. |
| Steering versus activation replacement | fixed in code | `Intervention` refuses `kind='replace'` with a nonzero strength and exposes `is_steering`/`is_patching`; patching has no dose grid and sources a real activation from a different held-out prompt. |
| SAE diagnostics and feature examples | fixed in code, blocked on real run | `paper_sae.py` is one defensible unsupervised path: explicit `n_features` (no "same as input" default), TopK by default, genuine weight tying, unit-norm decoder, train-only input normalization, `freeze()` before held-out evaluation, and full diagnostics (MSE, variance explained, L0, dead features, activation frequency, seed stability). Feature ranking uses train+validation only; selected features are scored once on test. `docs/SAE_AUDIT.md` records why the legacy module was not migrated. |
| Figures from real artifacts | fixed in code, blocked on real run | `paper_figures.py` has no mock path: each builder returns `not_run` with a reason when its artifact is absent. Every figure ships its source CSV, and `figures_manifest.json` records the artifact and its SHA-256, so `audit_figures` detects deleted, orphaned, or stale figures. Palette validated for CVD separation; per-series markers and the source CSV supply the required secondary encoding. |
| Concrete examples, labeling prompts, composition | partially fixed | real dataset adapted and characterised: `poker_adapter.py` emits the canonical schema plus parsed metadata and a composition report with integrity flags; see `docs/POKER_DATASET_NOTES.md`. **Upstream label provenance is still undocumented** and must be stated before publication. |
| Early stopping and stale metrics | fixed in legacy probe path | deep copied checkpoint; metrics recomputed after restore |
| Calibration, PR-AUC, and uncertainty | fixed in code, blocked on real run | PR-AUC, grouped bootstrap CIs, ECE in `compute_binary_metrics`, and group-level learning curves with multiple independent subsamples per size (`paper.py:run_learning_curve`) |
| Exact intervention timing and dose | fixed in code, blocked on real run | every record logs kind, layer, site, token index, timing policy, strength, direction name/source/norm, hidden norm, and `relative_magnitude` in units of the hidden-state norm; strengths are a configurable dose grid. |
| Quality degradation versus behavioral change | partially fixed | `summarize_quality` reports per-condition choice validity (`valid_choice_mass`, format adherence) beside every effect; `score_generation_quality` covers refusal/repetition/length for free-form conditions. | Overstated terminology / reasoning-trace framing | partially fixed | README guardrail; manuscript rewrite remains |
